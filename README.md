Чтобы начать марафон?

- привязка к чату
- привязка к людям (минимум 1 человек) (здесь создается цель отчет)
- минимум одна цель у каждого человека помимо отчета
- поставить дату начала марафона
    - она не должна быть сегодняшней (только завтра можно)
    - (остальные настройки остаются по default)

без этих условий марафон начинаться не будет и будет сдвигаться на день вперед
